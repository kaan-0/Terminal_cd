# Pruebas CD Terminal 1.4.0

## Instalacion

- [ ] El instalador actualiza una version anterior sin crear una copia paralela.
- [ ] El icono aparece en el instalador, ejecutable, escritorio y menu Inicio.
- [ ] CD Terminal abre correctamente en Windows 10/11 x64.

## Modulos

- [ ] Terminal serial conecta, transmite y recibe.
- [ ] Modbus RTU mantiene lectura, polling, CSV y grafica.
- [ ] Terminal SSH conecta y conserva TAB e historial.

## Configurador IoT V17

- [ ] Los desplegables personalizados abren correctamente.
- [ ] SHOWAUTH identifica el dispositivo y estado del token.
- [ ] DHCP e IP estatica se guardan correctamente.
- [ ] SETSERIAL y las cuatro ranuras de sensores funcionan.
- [ ] Produccion HTTPS muestra `rs485.cdtechnologia.net` y puerto 443.
- [ ] Guardar produccion envia la URL completa HTTPS y el intervalo.
- [ ] El modo personalizado conserva compatibilidad con URL completa o ruta local.
- [ ] La prueba `<ID>sensorZ` recibe un codigo HTTP 2xx.
- [ ] La terminal muestra la respuesta de la API.
