# Pruebas recomendadas para CD Terminal 1.2.0

## Instalacion

- Instalar sobre la version anterior.
- Confirmar que solo existe una entrada de CD Terminal.
- Abrir desde el menu Inicio.
- Probar el acceso directo del escritorio si se selecciono.

## Configurador IoT

- Conectar y desconectar un puerto COM.
- Cargar configuracion desde el equipo.
- Probar DHCP e IP estatica.
- Guardar servidor, puerto, periodo y URL.
- Enviar SETSERIAL.
- Enviar SETMODBUS.
- Ejecutar SHOWMODBUS.
- Ejecutar TESTMODBUS.
- Reiniciar el controlador.
- Verificar scroll en pantalla de laptop.

## SSH

- Conectar a un servidor por IP.
- Aceptar una huella nueva.
- Reconectar usando la huella guardada.
- Ejecutar whoami, hostname, uptime y df -h.
- Probar Ctrl+C con ping.
- Probar historial con flechas arriba y abajo.
- Probar TAB con nombres de comandos.
- Probar TAB con rutas, archivos y directorios.

## Release

- Ejecutar Scripts\verificar-release.ps1.
- Guardar el SHA-256 del instalador.
