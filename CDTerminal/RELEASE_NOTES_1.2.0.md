# CD Terminal 1.2.0

## Novedades

### Terminal SSH

- Conexion a servidores Linux y otros equipos con SSH.
- Autenticacion con usuario y contrasena.
- Verificacion y almacenamiento local de huellas conocidas.
- Terminal interactiva.
- Envio de Ctrl+C.
- Historial de comandos mediante flechas arriba y abajo.
- Autocompletado con TAB para comandos, rutas, archivos y directorios.

### Configurador IoT V13

- Interfaz dividida por secciones.
- Red y conectividad.
- Sensor RS485 y Modbus RTU.
- Envio de datos HTTP.
- Acciones del sistema.
- Diseno con desplazamiento vertical para evitar cortes en pantallas de laptop.

### RS485 y Modbus

- SETSERIAL con velocidades entre 1200 y 115200 bps.
- Paridad N, E y O.
- SETMODBUS con esclavo, funcion, registro inicial y cantidad.
- SHOWMODBUS para consultar configuracion.
- TESTMODBUS para probar el sensor.

## Compatibilidad

- Windows x64.
- Publicacion self-contained.
- Actualizacion sobre instalaciones anteriores mediante el mismo AppId.
