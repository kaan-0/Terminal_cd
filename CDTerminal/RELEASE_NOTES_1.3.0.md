# CD Terminal 1.3.0

## Configurador IoT V16

- Desplegables RS485 y Modbus hechos a medida para Blazor Hybrid.
- Configuracion de ID y token del dispositivo.
- Validacion del token entre 32 y 64 caracteres alfanumericos.
- Configuracion de red y API.
- Hasta cuatro sensores Modbus RTU.
- Comandos SETSENSOR, ENABLESENSOR, DISABLESENSOR, CLEARSENSOR, SHOWSENSORS, TESTSENSOR y TESTALL.

## Nuevo icono

- Nuevo simbolo de concentrador IoT con nodos de comunicacion.
- Aplicado al ejecutable de CD Terminal.
- Aplicado al instalador de Inno Setup.
- Aplicado a los accesos directos y al desinstalador.

## Compatibilidad

- Windows x64.
- Publicacion self-contained.
- Actualizacion sobre instalaciones anteriores mediante el mismo AppId.
