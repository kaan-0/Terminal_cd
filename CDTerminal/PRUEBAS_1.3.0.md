# Pruebas recomendadas para CD Terminal 1.3.0

## Icono e instalacion

- Confirmar que el Setup muestra el icono nuevo.
- Confirmar que CD Terminal aparece con el icono nuevo en Inicio y en la barra de tareas.
- Instalar sobre la version anterior y confirmar que no crea una copia paralela.

## Configurador IoT V16

- Abrir los desplegables de baud rate, paridad y funcion Modbus.
- Configurar ID y token.
- Consultar SHOWAUTH.
- Configurar DHCP o IP estatica.
- Configurar servidor, puerto, intervalo y URL.
- Configurar las cuatro ranuras de sensores.
- Ejecutar SHOWSENSORS, TESTSENSOR y TESTALL.
- Probar lectura y envio mediante <ID>sensorZ.

## SSH

- Conectar a un servidor.
- Probar historial con flechas arriba y abajo.
- Probar TAB con comandos, archivos y directorios.

## Release

- Ejecutar VERIFICAR-RELEASE.cmd.
- Guardar el SHA-256 del instalador.
