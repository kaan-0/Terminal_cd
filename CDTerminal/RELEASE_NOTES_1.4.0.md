# CD Terminal 1.4.0

## Configurador IoT V17 Produccion HTTPS

- Endpoint de produccion integrado: `https://rs485.cdtechnologia.net/api/v1/mediciones`.
- Protocolo HTTPS y puerto efectivo 443.
- La seccion de red queda enfocada en la conectividad local del controlador.
- La seccion Envio de datos ofrece Produccion HTTPS y modo Personalizado.
- Se conserva el flujo de ID, token, RS485 y cuatro sensores Modbus RTU.
- La terminal reconoce protocolo, puerto efectivo, codigos HTTP y mensajes TLS.

## Aplicacion

- Terminal serial RAW.
- Modbus RTU.
- Terminal SSH con historial y autocompletado.
- Publicacion Windows x64 self-contained.
